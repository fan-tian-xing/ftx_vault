# 泊松分布和指数分布的分布律
![](assets/随机过程第三章/file-20260626144749114.png)
**指数分布的密度函数**
$$f(y) = \begin{cases} \lambda e^{-\lambda y}, & y \ge 0 \\ 0, & y < 0 \end{cases}$$$$P(X > t) = e^{-\lambda t} \quad (t \ge 0)$$
<font color="#ff0000">注意，</font>泊松分布的均值为参数$\lambda t$,方差为$\lambda t$
       指数分布的均值为参数$1/\lambda$,方差为$1/\lambda^2$
