# 常返类是闭集

如果互通类C不是闭集，那么存在i属于C，j不属于C，i可达j，又因为j不可达i（因为j不属于C），故$P_j(\tau_i < \infty) = P_j(V_i = \infty) = 0$，故i不常返。
